# NSW PSN reference data

Seed data for the NSW Public Safety Network (P25, WACN BEE00, System ID 0x2D1).
Retrieved **2026-10-08**. Generated by one-off scripts; edit the CSVs by hand or regenerate them.

## `psn_talkgroups.csv` (2,285 rows)

`tgid,alpha_tag,description,agency,category,encrypted,source`

- `tgid`: decimal talkgroup ID.
- `alpha_tag`: up to 16 characters. It is built from the radio alias the source publishes, with the leading channel number removed and an agency prefix added (e.g. `105 CENCO A` becomes `RFS CENCO A`). If the source gives no alias, the tag is made from the description. If the talkgroup has no name, the tag is `<prefix> <tgid>`.
- `description`: the name from the source. The raw radio alias is kept as `[radio alias: …]`. When the second source gives a different name, it is recorded as `alt name per publicsafetynetwork.com.au: '…'`. Talkgroups that appear on a different agency page, or come only from the secondary source, are flagged in this field.
- `agency`: one of RFS, FRNSW, SES, NSWA, NSWPF, NPWS, TfNSW, RMS (TfNSW Roads, formerly RMS), VRA, MRNSW, CORRECTIVE or OTHER. OTHER rows begin with the owner, e.g. `Ausgrid: …`.
- `category`: a heuristic grouping based on keywords: District, Area Command, Dispatch, Operations, Fireground, Tactical, Strike Team, Patch, Interop, Aviation, Training, Zone Operations, Incident, Hospital, Admin, Support, Encrypted, Unknown. Treat it as a rough guide only.
- `encrypted`: `full` when the source marks the talkgroup "(ENC)"/encrypted, or says the whole agency is encrypted (NSWPF, AFP, Corrective Services, Sheriff). `clear` only for the ACT Government talkgroups, which nswpsn lists as non-encrypted. Empty means the source does not say. It does **not** mean clear.
- `source`: the URLs that contributed to the row, separated by semicolons.

Sources:
- Primary: https://www.nswpsn.com (all agency pages; site revision log at /site-revision). Its RFS page was last updated 2023-02, FRNSW 2025-02 and SES 2025-06. It reflects the current RFS Area Command and SES Zone structures, so it was treated as the most recent source and its names win.
- Secondary: https://www.publicsafetynetwork.com.au (e.g. /NSWRuralFireService.html). This site has no dates. Its names follow older structures (RFS East/North/West regions, pre-2021 SES regions such as "Oxley" and "Sydney Northern"). It is used to fill names nswpsn leaves blank, to add talkgroups nswpsn does not list (flagged `not listed on nswpsn.com`), and as alternative names.

Caveats:
- publicsafetynetwork.com.au's `/AmbulanceNSW.html` page currently shows a copy of the RFS table, so it was ignored.
- http://www.bathurstscan.com/frequency-lists/nsw-digital-grn/nsw-grn-talkgroup-list/ was **not used**. It is a RadioReference-format export (Decimal / Alpha Tag / Description / Service Tag / Category, with RR service tags and category names) from the old GRN era, e.g. "RFS GD28 GOSFORD" and "Integral Energy". Only 19 of its talkgroup IDs are missing from this file.
- No radioreference.com data was used.
- nswpsn.com's footer says its content "may only be reproduced with permission and acknowledgement of nswpsn.com". The product owner is handling licensing, and provenance is kept per row.
- nswpsn publishes no names for NSWPF or AFP talkgroups (redacted). Those rows are placeholders with `encrypted=full`.
- The RFS Lake Macquarie, Gosford and Wyong districts were merged into Central Coast, so there is no separate Lake Macquarie talkgroup (use CENCO A 10047 / CENCO B 20026).

## `psn_sites_acma.csv` (7,505 rows)

`site_id,site_name,latitude,longitude,state,postcode,freq_hz,emission,eirp_w,licence_no,client_name`

There is one row per (ACMA site, transmit frequency). Source: ACMA Register of Radiocommunications Licences bulk extract `spectra_rrl.zip` (https://www.acma.gov.au/register-radiocommunication-licences-rrl, file at https://web.acma.gov.au/rrl-updates/spectra_rrl.zip, extract dated 2026-10-08; table docs at https://cdn.acma.gov.au/offline-rrl/index.html).

Filter applied: licences held by NEW SOUTH WALES GOVERNMENT TELECOMMUNICATIONS AUTHORITY (ABN 85430594829, all 10 client numbers: "Telco Authority (PSN)", "(HGSA)", "(RFS)", "(FRNSW)", "(NSW Ambulance)", "(SES)", "(Essential Energy)", "(Repeaters)", "(Other Agencies)", "(OEH)"), plus `DEVICE_TYPE = T`, `CLASS_OF_STATION_CODE = FB` (base stations), a site present, and a frequency of 403–430 MHz or 450–470 MHz. Most PSN trunked-site channels sit under the "(HGSA)" client, and some under "(PSN)".

- `site_id`/`site_name`/`latitude`/`longitude`/`state`/`postcode` come from ACMA `site.csv`. The site name is ACMA's free-text location, e.g. "NSWTA 30m Lattice Tower Bumble Hill … WYONG CREEK". It is **not** the P25 RFSS/site number, and ACMA does not record that number.
- `freq_hz` is the transmit frequency. `emission` is the ACMA emission designator (`10K1F9W`/`20K4D7W` are typical P25). `eirp_w` is the maximum EIRP in watts across the matching devices.
- `licence_no`/`client_name` list every licence and client for that site and frequency, separated by semicolons.
- 403 FX (fixed), 74 ML (mobile) and 81 site-less FB transmitter records were excluded. A few cross-border sites (VIC/QLD/ACT) are included.

## `psn_sites_summary.csv` (1,288 rows)

`site_id,site_name,latitude,longitude,tx_count,freqs_mhz`: one row per site. `freqs_mhz` lists the site's distinct transmit frequencies, sorted and separated by semicolons.

**Attribution (required for the ACMA-derived files):** Based on Australian Communications and Media Authority information.
