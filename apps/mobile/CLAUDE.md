# CLAUDE.md

Guidance for coding agents (and people) working in `apps/mobile`. The monorepo
overview is in the root [README](../../README.md); releases are in
[docs/mobile-releases.md](../../docs/mobile-releases.md).

## Stack

- Expo SDK 57, React Native 0.86, React 19.2, TypeScript (strict).
- pnpm 10 (`pnpm install --frozen-lockfile`). Not yarn or npm.
- Navigation: Expo Router, file-based, routes in `src/app/`. The tab bar is
  `expo-router/unstable-native-tabs` (`NativeTabs`) for the native iOS tab bar.
- State: Zustand stores in `src/stores/` (auth, preferences, subscriptions).
- Data: TanStack Query hooks in `src/hooks/` over the typed REST client in
  `src/services/api-client.ts` (the Go server's `/api/v2/mobile` API, JWT auth).
  Live messages arrive over SSE (`/api/v2/mobile/events`).
- Push: React Native Firebase Messaging + Notifee.
- Purchases: `expo-iap` (`src/services/purchase-service.ts`). iOS sends the
  signed transaction (`getTransactionJwsIOS`) to the server, which verifies it;
  Android sends the purchase token. Entitlement always comes from the server.
- i18n: `src/i18n/` (en, ja).

There is no MobX, MST, GraphQL, Adapty, react-native-iap or React Navigation
stack/tab/drawer code any more; don't reintroduce them.

## Commands

```sh
pnpm dev                       # Metro for the dev client
pnpm ios | pnpm android        # native rebuild (expo run:*)
pnpm exec tsc --noEmit         # type check (CI runs this)
pnpm verify:decoder-patch      # regression for the decode-uri-component patch
pnpm verify:auth-store-race    # regression for the account-switch race
eas build --platform ios --profile preview --local   # simulator build
```

## Rules of thumb

- `ios/` and `android/` are generated by `expo prebuild` and git-ignored. Make
  native changes through `app.config.js`, `app.base.json` plugins or
  `expo-build-properties`, never by editing the generated projects.
- Keep `react-native-worklets` (peer of `react-native-reanimated` 4.x).
- Firebase pods need `useFrameworks: "static"` plus `forceStaticLinking`.
- Configuration comes from `EXPO_PUBLIC_*` variables and EAS environments (see
  `.env.example` and the root README). Never hard-code a production URL,
  provider key or project ID; a fork must not silently talk to rfspager.app.
- Bundle ID / package: `io.devlan.rfspager`.
- Use synthetic data in tests and screenshots, never real pager messages.
